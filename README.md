# Trust & Will Planning — Mesa Group Consulting

Standalone prototype for the **Trust & Will Planning** landing page, powered by Trust & Will.

Guides individuals and families through creating legally valid wills, trusts, and estate plans online, with attorney-reviewed documents at a fraction of traditional legal costs.

## Tech Stack
React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui
